# qiuku-alert 秋裤预警穿衣模拟器

冷空气南下，"一夜入秋"——每天为 8 个城市出差的你挑选穿搭，
7 天后按健康 + 时尚结算称号。冻成狗还是穿搭王者，全看你和老天爷的配合。

## 热点来源声明

灵感来自 2026 年 10 月 6 日冷空气南下新闻：武汉、南京 6 日最低
10–11℃，杭州、长沙、南昌最高 20℃，"一夜入秋"，全网玩"秋裤预警"梗。
本项目为善意玩梗的原创小游戏，与任何真实人物、企业无关。

## 温度数据声明

内置 8 城体感温度为**按新闻合理虚构的演示数据，非实况天气预报**：

| 城市 | 体感 | 备注 |
|------|------|------|
| 武汉 | 11℃ | 一夜入秋 |
| 南京 | 10℃ | 一夜入秋 |
| 杭州 | 20℃ | 最高 20℃ |
| 长沙 | 20℃ | 最高 20℃ |
| 南昌 | 20℃ | 最高 20℃ |
| 重庆 | 20℃ | 最高 20℃ |
| 北京 | 8℃ | 北方更冷 |
| 广州 | 28℃ | 广东人还在穿短袖（彩蛋） |

每日会在此基础上 ±2℃ 抖动。出门请看真正的天气预报，本游戏不负责你冻感冒。

## 玩法

1. 每天先看 8 城**预报**温度，为每城选一套穿搭；
2. 选完揭晓当日**随机事件**（预报不包含它，这就是人生）；
3. 按保暖值 vs 体感需求结算每城：

| 穿搭 | 保暖 | 时尚 |
|------|------|------|
| 短袖 | 1 | 8 |
| 长袖 | 3 | 6 |
| 外套 | 5 | 7 |
| 秋裤 | 6 | 2 |
| 羽绒服 | 9 | 3 |

- 保暖缺口 > 1 → **冻成狗**（健康 -2）
- 保暖超出需求 > 2 → **热成狗**（时尚 -1）
- 命中舒适区 → **穿搭王者**（健康 +1，时尚 +1）
- 穿秋裤额外**秋裤护体**（健康 +1，时尚就别想了）

### 随机事件

| 事件 | 效果 |
|------|------|
| 秋裤预警（红色警报） | 随机一城一夜降温 8℃ |
| 倒春寒式回温 | 随机一城回温 +6℃，穿多了热成狗 |
| 妈妈来电 | 随机一城强制换上秋裤，"多穿点！"，健康 +2 |
| 风平浪静 | 无事发生，珍惜 |

### 7 天后称号

| 称号 | 条件 | 评语摘录 |
|------|------|----------|
| 穿搭王者 | 健康 ≥70 且时尚 ≥60 | 朋友圈的人间天气博主 |
| 秋裤战神 | 秋裤 ≥20 次 | 时尚是什么？能当暖气用吗？ |
| 要风度不要温度 | 时尚 ≥60 且健康 <40 | 暖气片没有你的一席之地 |
| 老寒腿预备役 | 冻成狗 ≥12 次或健康 <30 | 秋裤是妈妈的爱，穿上吧 |
| 平平无奇穿衣人 | 其他 | 秋裤在衣柜里为你鼓掌 |

## 运行

```bash
# 交互模式（需要终端）
python3 -m qiuku_alert

# AI 自动演示：贪心按预报温度选最接近需求的穿搭
python3 -m qiuku_alert --auto --games 10 --seed 42

# 打印每日战报
python3 -m qiuku_alert --auto --games 1 --seed 7 --verbose
```

纯 Python 标准库（argparse / random / sys），Python 3.10+。

## 诚实的局限

- 温度、事件概率、保暖/时尚数值均为拍脑袋设定的演示值，无真实气象模型，不做任何穿衣建议。
- 贪心 AI 几乎必胜（100 局 100 次穿搭王者）：它按预报选最优解，人类玩家面对揭晓后的"一夜降温 8℃"才是真实难度。数值平衡未经大规模调参。
- 事件纯随机 + 简单触发，没有冷空气传播过程模拟。
- 纯文本界面，无图形、无存档、无网络对战。
- 需要 Python 3.10+（用了 `X | None` 注解语法）。
